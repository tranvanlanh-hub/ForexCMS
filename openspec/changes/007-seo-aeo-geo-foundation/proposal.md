# Change 007 - SEO/AEO/GEO foundation

## Summary

Build the first reusable SEO/AEO/GEO foundation for published public content pages.

## Goals

- Ensure public content pages render SEO title, meta description, canonical URL, robots metadata, visible breadcrumb, and basic JSON-LD.
- Support Article, BreadcrumbList, and FAQPage JSON-LD.
- Generate a basic sitemap index and segmented sitemap route ready for 4,000+ URLs.
- Generate robots.txt.
- Keep one visible H1 per public content page.
- Keep canonical URLs market-scoped and language-aware through page metadata/hreflang structure.

## Non-goals

- Full SEO Manager admin UI.
- Full hreflang relationship editor.
- Full template-specific schema for every future template.
- Large background sitemap generation jobs.
